# inchwright-site

The landing page, privacy policy and support page for **Inchwright**, a physics puzzle game for iPhone (coming soon
to the App Store).

Live at https://nguyenvanlamm.github.io/inchwright-site/

Plain static files with no build step. GitHub Pages serves the root of the `main` branch.

| File | Purpose |
|---|---|
| `index.html` | Landing page |
| `privacy.html` | Privacy Policy (App Store privacy policy URL) |
| `support.html` | Support (App Store support URL) |
| `assets/` | App icon, favicons, screenshots, Open Graph card |
| `sitemap.xml`, `robots.txt`, `llms.txt` | Crawlers and AI agents |

To preview locally, open `index.html` in a browser.
